Django - высокоуровневый веб-фреймворк на языке Python, предназначенный для быстрого создания надёжных и масштабируемых веб-приложений. Он помогает разработчикам создавать сайты и веб-сервисы без необходимости писать всё с нуля.

Фреймворк - набор инструментов и библиотек, помогающих решать типичные задачи при создании веб-приложений:

* Обработка запросов и маршрутизация URL
* Работа с базой данных
* Создание HTML-шаблонов
* Формы и валидация данных
* Аутентификация пользователей
* Панель администратора

Преимущества:

* Скорость разработки
* Безопасность - встроенная защита от SQL-инъекций, XSS, CSRF и т.д.
* Масштабируемость - используется в крупных проектах с миллионами пользователей
* Админ-панель - автоматическое создание интерфейса управления данными
* Гибкость - поддержка API, кастомных моделей, приложений и т.д.

Подходит для: лендингов, сайтов-визиток, CRM, CMS, блогов, новостных порталов, внутренних панелей, интернет-магазинов, REST API для мобильных приложений, интерфейсы для Data Science / аналитики.

Архитектура Django – MTV:

* Model - описание данных и логики БД
* Template - отвечает за HTML-шаблоны и отображение
* View - содержит логику обработки запросов

Возможности:

* Создание веб-сайтов с динамическим контентом
* Работа с БД через ORM (без SQL)
* Генерация HTML-страниц через шаблоны
* Создание REST API через DRF
* Обработка форм и загрузка файлов
* Регистрация пользователей и аутентификация
* Управление проектом через админку

Файлы

* `manage.py` - главный управляющий скрипт. Используется для запуска сервера, миграций и других команд. Входная точка. Командная утилити для управления Django-проектом. Обёртывает `django-admin` и передаёт ему настройки проекта. Помогает запускать сервер, создавать/применять миграции, создавать суперпользователя, открывтть Django shell. Знает, где лежат настройки (settings.py) и подключает их при каждом запуске. Используется для управления проектом через команды.
* `settings.py` - файл с настройками проекта (БД, приложения, локализация)
* `urls.py` - маршруты проекта: какие адреса обрабатываются какими функциями
* `asgi.py` и `wsgi.py` - файлы для запуска сервера в разных режимах (production/development)
